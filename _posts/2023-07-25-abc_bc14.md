### 생각의 틀이란?


생각하는 방법, 사고법으로

가설, 모델, 이론, 법칙, 프레임워크

의 범주로 이루어져있다.

​

항상 자기만의 생각의 틀을 만들어야 한다고

강조하셨다. 새로운 생각의 틀은

새로운 나를 만들어가는 과정이라고 한다.

​

​

### 모델링 이론

​

| 물리 세계(Pysical) | 정신 세계(Mental)       | 가상 세계(Virtual) |
| :------------- | ------------------- | -------------- |
| 감각(Sense)->    | <- 감성(Sensibillity) | 인간이 만든 세계      |
|                |                     |                |

## <2> 꿈을 잇(IT)다 - 채은경 대표님

​

![image](https://github.com/user-attachments/assets/a699f5cd-4866-4846-8ff2-c1e2d6e74f8c)

​

현재 ABC 부트캠프를 운영하고 있는

(주)유클리드 소프트의 대표자이신 채은경 대표님께서는

유클리드 소프트를 설립하기 까지의 발자취와

스페셜리스트와 제너럴리스트에 대해 강연하셨다. 

| 제너럴 리스트 (Generalist)

지도자 / 다방면에 능한 사람

| 스페셜 리스트 (Specialist)

전문가 / 전공자 / 특기를 가진 사람




경계인 / 한계인 / 주변인

경계인은 borderline 이라고 하면, 

​

수많은 경계인들(같은 개방자, 돈만보거나, 기술의 한계)의

시선을 넘어 나는 그들보다 더 빨리 한걸음을 내딛고 나아가는 사람이 

되자는 뜻으로 마무리를 짓고,  

정말 유용하고 소중한 기회의 특강 시간이었다.
